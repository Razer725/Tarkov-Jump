# Tarkov Jump

Локальная браузерная аркада в духе Doodle Jump с атмосферой рейда.

## Запуск

Самый простой способ — запустить `start-game.bat` двойным щелчком. Откроется браузер с игрой; служебное окно нужно оставить открытым до конца игры.

Также можно открыть `index.html` напрямую или запустить сервер из этой папки вручную:

```powershell
node server.js
```

После этого открыть <http://localhost:8080>.

## Управление

- `A` / `D` или `←` / `→` — движение.
- `W` или `↑` — двойной прыжок (восстанавливается после приземления).
- `Пробел` — стрельба.

На оружейных платформах можно подобрать дробовик (веер дроби), пистолет-пулемёт (короткие очереди) или пулемёт (скоростной автоматический огонь). Подобранное оружие сразу получает полный магазин.
- `P` или `Esc` — пауза.
- `Enter` — начать рейд.
- `R` — новый рейд после поражения.

На сенсорных устройствах появляются экранные кнопки.

## Цель

Поднимайтесь по платформам, собирайте припасы и лут, избегайте огня противников. Точка эвакуации находится на высоте 5000 метров.
