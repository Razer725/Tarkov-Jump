# Tarkov Jump

Локальная браузерная аркада в духе Doodle Jump с атмосферой рейда.

## Запуск

Самый простой способ — открыть `index.html` двойным щелчком. Игра работает в браузере без Node.js, установки зависимостей и интернета. Если HTML-файлы открываются в редакторе, нажмите правой кнопкой на `index.html` → «Открыть с помощью» → выберите браузер.

В Windows также можно запустить `start-game.bat`: он открывает тот же `index.html` в браузере по умолчанию. Служебное окно оставлять открытым не нужно.

Перед запуском распакуйте всю папку игры из архива: рядом с `index.html` должны находиться `styles.css`, `storage.js`, `game-model.js` и `game.js`.

Для разработки при необходимости можно запустить локальный сервер (только для этого нужен Node.js):

```powershell
node server.js
```

После этого открыть <http://localhost:8080>.

## Структура и проверки

- `game-model.js` — состояние рейда, физика, генерация мира и игровые механики. Работает без браузера; передаёт уведомления, звук и результат через callbacks.
- `game.js` — Canvas, HUD, экраны, управление и звук. Изменяет HUD только при изменении отображаемых значений.
- `storage.js` — настройки и рекорд; если браузер запрещает хранилище, изменения сохраняются в памяти до закрытия страницы.
- `server.js` — локальный сервер с явным списком публичных файлов. При добавлении ресурса для браузера его нужно внести в этот список.
- `index.html`, `styles.css` — разметка и оформление.

Проверки на Node.js 18 или новее, без установки зависимостей:

```powershell
node --test tests/project.test.js
```

## Управление

- `A` / `D` или `←` / `→` — движение.
- `W` или `↑` — двойной прыжок (восстанавливается после приземления).
- `Пробел` — стрельба.

На оружейных платформах можно подобрать дробовик (веер дроби), пистолет-пулемёт (короткие очереди) или пулемёт (скоростной автоматический огонь). Подобранное оружие сразу получает полный магазин.

Персонаж начинает рейд без защиты. По пути встречаются броня и шлемы трёх тиров: лёгкие снижают урон по своей зоне на 20%, средние — на 40%, тяжёлые — на 60%. Более высокий тир заметно массивнее и автоматически заменяет экипировку ниже уровнем. После каждых трёх пулевых попаданий в защищённую зону соответствующий предмет теряет один тир; броня и шлем первого тира после третьего попадания уничтожаются.
- `P` или `Esc` — пауза.
- `Enter` — начать рейд.
- `R` — новый рейд после поражения.

На сенсорных устройствах появляются экранные кнопки.

Перед началом рейда в меню можно включить «Неуязвимость от врагов». В этом режиме пули и столкновения с противниками не отнимают здоровье, но падение за пределы карты по-прежнему завершает рейд. Выбор сохраняется для следующих запусков.

## Цель

Поднимайтесь по платформам, собирайте припасы и лут, избегайте огня противников. Каждые 5000 метров меняется локация и растёт сложность: Эпицентр → Таможня → Развязка → Резерв → Лаборатория. Финальная точка эвакуации находится на высоте 25000 метров.
